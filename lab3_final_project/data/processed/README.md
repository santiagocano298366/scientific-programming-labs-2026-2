# data/processed

Files saved by `main.py`:

* `cleaning_steps.csv`: rows and curves left after each cleaning step.
* `usable_curves.csv`: one row per usable curve (points, psi range, texture group, site, reference).
* `selected_points.csv`: the measured points of the usable curves.
* `features.csv`: the 13 features of each curve and its labels.
